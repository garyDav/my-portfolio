# Calculadora con React Native

## Crear Proyecto

Instalamos con el siguiente comando:

```bash
# Instalar Expo CLI
pnpm create expo-app

# app named
calculator-app
# Select an Expo SDK version:
[*] Select an Expo SDK version:

# Renombrar el proyecto
mv calculator-app 04-calculator-app
cd 04-calculator-app

# Ejecutar el proyecto
pnpm start

# Si queremos exponer en nuestra red local, podemos usar el siguiente comando con IP de Windows:
REACT_NATIVE_PACKAGER_HOSTNAME=192.168.100.116 pnpm start
```
